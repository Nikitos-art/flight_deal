# Flight Deals Finder (Learning Project)

## Overview

This project is based on the **“100 Days of Code: The Complete Python Pro Bootcamp”** course on Udemy by Dr. Angela Yu.

It is a learning project focused on building a simple system that searches for flight deals and processes travel data using external APIs.

---

## What it does

* Retrieves destination data from an API
* Uses a flight search service (Kiwi/Tequila API) to find available flights
* Compares prices and organizes flight information
* Prepares notifications when good deals are found

---

## Structure

The project is organized into multiple modules, each responsible for a specific task:

* handling flight searches
* managing data from APIs
* structuring flight information
* sending notifications

---

## Notes

* This project is based on course material and follows the structure and concepts taught by Dr. Angela Yu
* It was used for learning purposes and experimentation with APIs and Python classes
* Some parts may be simplified or not production-ready

---

## Purpose

The goal of this project was to:

* practice working with external APIs
* understand project structure and modular design
* build a small real-world style application in Python
